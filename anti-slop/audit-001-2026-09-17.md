## Numbered Findings List

### [Finding 01] — R-25: Color Contrast pada Portfolio Overlay
- **Rule:** R-25 (Color Contrast WCAG AA)
- **Priority:** HIGH (Hard Gate)
- **Tinjauan:** Pada `.portfolio-card-overlay`, metadata teks lokasi menggunakan `#E6E1DA` di atas gradien foto. Pada layar dengan kecerahan tinggi atau foto yang sangat terang, rasio kontras mendekati batas 4.5:1.
- **Rekomendasi Perbaikan:** Mempertegas gradien dasar ke `rgba(24, 21, 20, 0.92)` dan menambahkan `text-shadow: 0 1px 3px rgba(0,0,0,0.5)` demi jaminan kontras WCAG AA absolut.

### [Finding 02] — R-27: Image Fallback Error State pada Kartu Produk
- **Rule:** R-27 (UI States — Empty, Loading, Error)
- **Priority:** HIGH (Hard Gate)
- **Tinjauan:** Katalog sudah memiliki *Empty State* (`#catalog-empty-state`), namun elemen `<img>` pada katalog produk belum dilengkapi penanganan *Error State* (`onerror`) jika koneksi aset foto terputus.
- **Rekomendasi Perbaikan:** Menambahkan fallback SVG placeholder serat kayu bernuansa hangat secara otomatis saat gambar gagal dimuat.

### [Finding 03] — R-32: Keyboard Arrow Navigation pada Modal Thumbnail
- **Rule:** R-32 (Keyboard Accessibility)
- **Priority:** HIGH (Hard Gate)
- **Tinjauan:** Modal detail produk sudah mendukung navigasi Tab, Enter, dan tombol `ESC` untuk menutup. Namun, perpindahan antar-thumbnail foto masih memerlukan klik mouse/Enter terpisah per tombol thumbnail.
- **Rekomendasi Perbaikan:** Menambahkan event listener tombol panah kiri (`ArrowLeft`) dan kanan (`ArrowRight`) saat modal aktif agar pengguna keyboard dapat menjelajahi foto kriya dengan mulus.

### [Finding 04] — R-08: Tanda Panah Dekoratif pada Link Footer
- **Rule:** R-08 (Button Arrows)
- **Priority:** MEDIUM (Purpose-Gate)
- **Tinjauan:** Pada link Google Maps di footer terdapat karakter panah kanan (`Buka di Google Maps →`). Aturan R-08 membatasi tanda panah agar memiliki alasan jelas sebagai penunjuk navigasi keluar (*external link*).
- **Rekomendasi Perbaikan:** Mengganti karakter panah teks dengan ikon SVG *external link* kecil berstandar UI yang lebih proporsional.

### [Finding 05] — R-19: Micro-Transition pada Tab Filter Kategori
- **Rule:** R-19 (Animations & Motion Dial 2)
- **Priority:** MEDIUM (Purpose-Gate)
- **Tinjauan:** Perpindahan filter kategori saat ini instan tanpa animasi transisi kehalusan (*fade/opacity transition*) pada grid kartu produk.
- **Rekomendasi Perbaikan:** Menambahkan transisi kelembutan visual (200ms ease) saat kartu berganti filter kategori sesuai dengan target MOTION Dial 2.
